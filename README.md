# Ping — Frontend

This is the frontend client for **Ping**, a real-time chat application built with React, Vite, Tailwind CSS, and Framer Motion.

For full documentation, setup instructions, and API reference, see the **[main README](../README.md)** in the project root.

## Quick Start

```bash
npm install
npm run dev
```

The app will be available at `http://localhost:5173`.

## Scripts

| Command           | Description                        |
| ----------------- | ---------------------------------- |
| `npm run dev`     | Start the Vite development server  |
| `npm run build`   | Build for production               |
| `npm run preview` | Preview the production build       |
